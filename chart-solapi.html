준비물

  • 사업자등록증 — 솔라피에 기업/단체 계정으로 가입할 때.
  • 보내는 번호로 쓸 전화번호와 그 번호의 통신서비스 이용증명원 — 환자가 되걸었을 때 받을 수 있는 사무실 대표 전화를 권합니다. 이용증명원은 전화 통신사에서 받고, 발급한 지 6개월 안 · 가린 곳 없이여야 합니다.
  • 솔라피 계정 주인이 될 사람의 휴대폰 — 대표 또는 실무 담당자. 가입할 때 본인인증을 하고, 나중에 설정을 바꿀 때마다 2차 인증을 맡습니다.
  • 문자를 보낼 사무실 컴퓨터 — 솔라피는 등록해 둔 인터넷(IP)에서 온 요청만 받습니다. 숨길이를 쓰는 그 컴퓨터에서 연결합니다.
먼저 정해 두세요 — ① 보내는 번호로 어느 전화를 쓸지 ② 솔라피 계정 주인을 누구로 할지. 보내는 번호를 등록할 때 그 전화기 앞에서 전화를 받아야 하고, 전화 명의가 우리 업체가 아니면 위임 서류가 더 필요합니다.

연결 순서 7단계

1

통신서비스 이용증명원 받기 — 가장 오래 걸릴 수 있어 먼저

보내는 번호로 쓸 전화의 통신사(KT · LG U+ · SK브로드밴드 등) 고객센터나 기업 홈페이지에서 받습니다. 통신사 이름, 이용자(사업자등록번호), 전화번호, 발급일이 모두 보여야 합니다. 가입신청서 · 요금 납부내역서는 받아 주지 않습니다.

통신사마다 받는 방법은 솔라피 발신번호 안내의 "통신사 별 서류 발급 방법"에 있습니다.

2

솔라피 가입

solapi.com 에서 기업/단체 계정으로 가입합니다. 사업자번호를 넣고 대표자 또는 실무 담당자 명의로 본인인증을 합니다. 가입한 사람이 계정 주인이 됩니다.

가입 뒤 콘솔에서 사업자 인증과 2차 인증(구글 OTP 등)을 마칩니다. 가입하면 포인트 300점을 줍니다(솔라피 안내 기준). 그 뒤로는 콘솔에서 쓸 만큼만 충전합니다.

3

보내는 번호(발신번호) 등록

솔라피 콘솔 › 메시지 › 발신번호 › 새 발신번호 등록

  1. 번호를 넣습니다(지역번호까지).
  2. ARS 인증하기 — 그 번호로 걸려 오는 전화를 받아(또는 그 번호에서 직접 걸어) 화면의 4자리 숫자를 누릅니다. 계정 주인의 휴대폰으로 대신할 수 없습니다.
  3. 명의 확인 — 1단계에서 받은 통신서비스 이용증명원을 올립니다.
  4. 심사를 기다립니다. 솔라피 안내 기준 영업일 1~3일.

등록할 수 없는 번호: 착신전환 번호 · 투넘버(듀얼넘버) · 안심번호(050 · 030). 등록한 번호는 24개월 뒤 만료되며, 만료 전에 안내 문자가 오면 콘솔에서 갱신합니다.

4

사무실 인터넷의 '내 IP' 확인

문자를 보낼 컴퓨터에서 네이버에 '내 IP' 를 검색합니다. 123.45.67.89 처럼 숫자 네 덩이가 나옵니다. 이 숫자를 적어 둡니다.

같은 공유기에 물린 컴퓨터는 숫자가 같습니다. 컴퓨터마다 숫자가 다르면 보낼 컴퓨터의 숫자를 모두 적어 둡니다.

5

API Key 만들기

솔라피 콘솔 › API Key 관리 에서 새 키를 만듭니다. (2차 인증을 물을 수 있습니다)

  • 권한을 고르는 칸이 있으면 — 문자(메시지) 발송은 꼭 고릅니다. 잔액 조회도 같이 고르면 숨길이에 솔라피 잔액이 보입니다. 알림톡을 쓸 계획이면 카카오톡 조회도 같이 고릅니다.
  • 허용 IP — 4단계에서 적은 숫자를 넣습니다. 문자를 보내는 키는 허용 IP 가 꼭 있어야 합니다(2026-11-11부터).
  • 유효기간을 고르게 되어 있으면 길게 잡습니다.
API Secret 은 만들 때 한 번만 보입니다. 창을 닫기 전에 바로 6단계로 가서 숨길이에 붙여 넣으세요. 놓쳤으면 키를 새로 만들어야 합니다. API Key 와 Secret 은 통장 비밀번호처럼 다루고, 메신저 · 메일로 보내지 마세요.

콘솔 화면의 칸 이름은 솔라피가 바꿀 수 있어 여기 적힌 것과 조금 다를 수 있습니다.

7

연결 확인 → 나에게 시험 발송

  1. 🔌 연결 확인 을 누릅니다. 문자는 나가지 않습니다. ✅ 연결됨 이 나오면 됩니다.
  2. 📨 나에게 시험 발송 을 눌러 내 휴대폰에 문자가 오는지, 보낸 번호가 맞게 보이는지 확인합니다. 발신번호 심사가 끝난 뒤에 됩니다.
"✅ 연결됨 · 문자를 보낼 수 있습니다 · 잔액은 이 키로 읽지 못했습니다" 라고 나와도 정상입니다. 키에 잔액 조회 권한이 없을 때 이렇게 나오며, 보내는 데는 지장이 없습니다.

꼭 알아 둘 것

  • 등록한 인터넷에서만 보내집니다. 집이나 휴대폰 테더링에서는 보낼 수 없습니다. 사무실 인터넷이 고정 IP 가 아니면 공유기를 껐다 켜거나 통신사 점검 뒤에 IP 가 바뀔 수 있고, 그때는 위 표의 첫 줄대로 고칩니다. 허용 IP 는 계정 주인이 사무실 밖에서도(국내) 솔라피 콘솔에 들어가 고칠 수 있습니다.
  • 키는 컴퓨터(브라우저)마다 따로입니다. 숨길이 자료가 컴퓨터마다 따로이듯, 문자 설정도 쓰는 컴퓨터마다 넣습니다. 💾 백업 파일에는 키가 암호화된 채 함께 들어가므로, 백업 파일과 비밀번호를 함께 넘기면 키도 넘어갑니다.
  • 개인정보. 문자를 보낼 때 받는 번호와 문구(이름 · 금액)가 솔라피로 갑니다. 솔라피를 개인정보 처리위탁 업체로 동의서 · 처리방침에 적어 두세요.
  • 안내 문자용입니다. 본인부담금 · 방문 일정 · 처방 만료 같은 안내를 보내려고 만든 기능입니다. 광고 문자는 법에서 정한 표기(광고 표시 · 무료 수신거부 방법)와 사전 동의가 따로 필요합니다.
  • 밤 9시 ~ 아침 8시에 보내려 하면 숨길이가 한 번 더 알려 줍니다.
  • 값은 어림입니다. 화면의 예상 비용은 솔라피 가격 정책 기준으로 셈한 것이고, 실제로 빠진 금액은 솔라피 콘솔에서 봅니다. 한글 45자(90바이트)까지는 짧은 문자(SMS), 넘으면 긴 문자(LMS)로 나갑니다.
  • 솔라피 규정은 자주 바뀝니다. 이 설명서는 2026-11-22 기준입니다. 막히면 아래 솔라피 공지를 같이 보세요.

알림톡(카카오톡)도 쓰려면 — 선택

문자 대신 카카오톡으로 보내는 길입니다. 값은 건당 13원으로 문자보다 싸지만, 카카오가 미리 검수한 문구(템플릿)에 이름 · 금액 같은 빈칸만 바꿔 보낼 수 있습니다. 마음대로 쓴 글은 카톡으로 보낼 수 없고, 광고는 안 됩니다.

  1. 카카오톡 채널 만들기 · 비즈니스 인증 — business.kakao.com. 사업자등록증과 대표자 신분증(또는 실명 인증)이 필요하고 며칠 걸릴 수 있습니다.
  2. 솔라피에 채널 연동 — 솔라피 콘솔의 카카오톡 채널 화면에서 채널 검색용 아이디 · 카테고리 · 담당자 휴대폰 번호를 넣습니다.
  3. 알림톡 템플릿 등록 · 검수 — 솔라피 콘솔에서 문구를 올리면 카카오가 검수합니다. 한 번 올린 템플릿은 고칠 수 없어 바꾸려면 새로 올립니다. 빈칸 이름을 #{이름} · #{월} · #{본인부담금} · #{결제일} · #{업체명} · #{업체전화} 로 지으면 숨길이와 저절로 이어집니다.
  4. 숨길이에서 켜기 — ⚙️ 설정 › 💬 문자 발송 맨 아래 💛 알림톡 칸에서 🔄 솔라피에서 채널 · 템플릿 불러오기 → 템플릿마다 보기 · 빈칸 짝짓기 확인 → [알림톡으로 보내기] 켜기.
  5. 보내기 — 본인부담금 안내 창과 환자 문자 창에 노란 알림톡 줄이 생깁니다. 템플릿을 고르면 카톡으로 가고, 카톡을 못 받는 분께는 같은 문구가 문자로 대신 갑니다(그때는 문자 값).
알림톡은 새로 넣은 기능이라 먼저 [나에게 먼저 보내기]로 내 휴대폰에서 확인한 뒤 쓰세요. 결제를 유도하는 문구(결제 링크 · 결제 단추)는 카카오가 추가 서류를 요구합니다. 본인부담금 안내는 링크 · 단추 없이 금액과 날짜만 알리는 글로 올리기를 권합니다.
